\subsection{Interpreting the Spreadsheet Discrepancy}
% Stock-level vs folio-level GT.
% The 7 large errors do NOT necessarily indicate pipeline failure -- the
% spreadsheet records the dominant laid count for a paper stock, but
% individual folios may originate from a different mould pair within
% the same stock. The two manually counted folios (Kk1-5 f5v/f9v)
% collapse the error to <1\%, supporting this interpretation.

\subsection{Limitations}
% - Octave aliasing when laid density approaches the Gabor period bank
%   upper bound or contrast is dominated by chain lines.
% - Wire-width recovery less reliable for sigma outside $[2,5]$ px.
% - Polarity (wire\_is\_darker) must be set per-modality; not auto-detected.
% - FOV scale calibration is per-image -- a wrong fov\_width\_cm propagates
%   linearly into lines/cm.

\subsection{Comparison with Prior Art}
% - Hiary \& Ng style projection FFT: simpler, but requires orientation

%   directional information available from DRP.

\subsection{Implications for Codicology}
