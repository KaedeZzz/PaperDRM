\section{Reproducibility}
\label{app:repro}

The complete source code for the pipeline, the analysis scripts, the
synthetic phantom generator, the manual ground-truth annotation tool
and every per-folio result archive is available at:
\begin{center}
\url{https://github.com/KaedeZzz/PaperDRM}
\end{center}
The exact revision against which the numbers in this report were
generated is commit \texttt{2565320}\,---\,the pipeline branch head
that produced the per-folio \texttt{results/<folio>/} archives.

\paragraph{Environment.}
The pipeline targets Python 3.10 or later. The full pinned dependency
list is in \texttt{requirements.txt} at the repository root; the
runtime requirement is a small set of standard scientific Python
packages (\texttt{numpy}, \texttt{scipy}, \texttt{matplotlib},
\texttt{opencv-python}, \texttt{tqdm}, \texttt{pillow},
\texttt{PyYAML}). A reproducible environment is created with:
\begin{verbatim}
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
\end{verbatim}

\paragraph{Per-folio configuration.}
Each folio is described by an \texttt{exp\_param.yaml} file
under its own subdirectory of \texttt{results/}, carrying the
data path, the optical scale, the polarity flag and the per-folio
period search band. A representative example for Kk.1.5 f5v reads:
\begin{verbatim}
data_serial: Kk1-5_f5v
data_root: data/msi/Kk1-5_f5v
fov_width_cm: 26.5146
crop_roi: [1006, 690, 4556, 6756]
subtract_background: true
line_dir_deg: 0.0
wire_is_darker: false
period_range_cm: [0.060, 0.180]
\end{verbatim}

\paragraph{End-to-end reproduction.}
With the repository cloned, the dependencies installed and the
relevant DRP or MSI imagery in place under \texttt{data/}, the full
pipeline for a single folio runs from \texttt{main.py}; the per-folio
outputs, the metric bundle, and the overlays appear under
\texttt{results/<folio>/}. No per-run manual tuning is required beyond
the YAML file shown above; the only exception is the narrowed period
range used for the sub-harmonic alias case discussed in
\Cref{sec:benchmark:msi:failures}.
